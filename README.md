# CXSY Group 小组专题网站

本仓库用于创新实验三“小组专题网站”展示。项目采用 Flutter Web 实现，页面集中整理小组分工、本地运行命令、截图证据清单和 Jekyll/静态网站边界思考。

## 运行

```powershell
flutter pub get
flutter run -d chrome --web-port 8080
```

访问地址：

```text
http://localhost:8080
```

## 实验三对应材料

- 页面源码：`lib/main.dart`
- 项目配置：`pubspec.yaml`
- 运行脚本：`run_flutter.bat`
- 截图建议：命令行运行截图、网页首页截图、GitHub 仓库截图、提交记录截图

```powershell
git add .
git commit -m "complete group topic website"
git push
```

## 页面内容

1. 实验目标：围绕小组专题完成本地运行与网页展示。
2. 小组分工：记录成员 GitHub 与贡献。
3. 本地运行：给出 Flutter Web 启动命令。
4. 证据清单：对应报告中的代码、命令行、网页、仓库截图。
5. 思考题：说明 Jekyll/静态网站适用场景和局限。
